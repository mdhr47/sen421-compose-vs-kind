Topic 8 — Kubernetes on kind versus Docker Compose

22 Nov 2026 — Setup and first experiments

I ran nginx on my Windows laptop using Docker Compose on port 8080 and a local Kubernetes cluster on port 8081. The cluster had one control-plane node and two worker nodes. Both setups served the same nginx image.

I tested what happened when I stopped nginx inside its container. I also tested what happened when Compose recreated the container and Kubernetes restarted the deployment. These were restarts using the same image. I saved the probe results as CSV files.

Files: docker-compose.yml, kind-config.yaml, web.yaml, web-tuned.yaml, environment.txt, and the original crash and update CSVs.

23 Nov 2026 — Checking whether the comparison was fair

I found that my original probe checked Compose about every 0.114 s and Kubernetes about every 0.625 s. A short outage was easier to miss on Kubernetes, so I kept those files as preliminary results.

I tested both addresses with Python on port 8081. All ten requests succeeded. The median request took 523.1 ms using localhost and 9.3 ms using 127.0.0.1. The old script waited another 100 ms after each request, which explains the roughly 625 ms gap I observed.

I switched both probes to 127.0.0.1 and checked the timing before repeating the crash test. Both platforms answered 30 out of 30 requests. The median gap between checks was 100.5 ms for Compose and 100.4 ms for Kubernetes.
